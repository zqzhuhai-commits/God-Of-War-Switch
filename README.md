# 战神 Switch 汉化版运行时移植补丁

面向 Nintendo Switch V1 / Tegra X1 / 原厂4GB内存，当前目标为 Horizon homebrew、ARM64原生C++和deko3d。不是Wine/Box64，也不是已完成的Switchroot L4T发行版。

基于 [Waffle565/switch](https://github.com/Waffle565/God-Of-War-Native-Port/tree/switch) 的 `63c90cb109356b0d46ef00f413f87a4e305ba4bc`，以补丁形式发布运行时改动，保留上游GPL-3.0许可和署名。

## 默认配置

手持/底座均约720p内部渲染、1280×720输出。`configs/`另有原始1倍、约540p内部渲染两套配置，输出也均为720p。内部倍率按448行基准换算，实际尺寸随场景变化。配置每项均有中文备注。

## 修改

- GOWS_169.41启动适配、低地址私有内存、IOP模块和DVD双层布局。
- 原生ARM64、VU1快速内核及预生成代码路径。
- MPEG回调和环形缓冲修正、普通话音轨0、欠载及队列截断的短交叉过渡。
- IOP函数直接索引、按需诊断、线程调度和deko3d固定状态拆分。
- 帧时钟入口0x17DB78的有限墙钟追赶，通过调度器同时推进EE计时器与IOP音频。保留游戏原始时钟计算；未移植美版额外credit/debt修改。

- 全屏调制分块覆盖对齐、实际分配尺寸的裁剪换算及像素中心修正；关闭转储时免去每批次的调试墙钟读取。

## 状态

ARM64 NRO和PC构建通过，时钟128组边界及无锚点/启动情况检查通过。PC可进入3D场景，但延长测试仍有间歇缺音。Switch多人战斗低帧率、断音尚未确认修复。已定位720p天空竖线到全屏调制批次：1/16像素分块端点的细缝被非整数倍率采样。匹配的全屏平面批次启用GOW_POSTPROCESS_SNAP=1后，PC逐批次抓图中固定竖线消失；Switch实机效果待验证。

`GOW_SPRITE_SAMPLE_CLAMP=0`仅供采样边界对照诊断，默认行为不变，尚不能作为竖线修复使用。
